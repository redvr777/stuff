Why "Kick from Photon" doesn't disconnect them immediately

This button writes a flag to PlayFab — it doesn't touch Photon directly, since Photon Cloud has no outside "kick" API. The actual disconnect happens inside your game: the room's Master Client needs to be running the KickWatcher.cs script, which checks PlayFab every few seconds and calls Photon's real kick (PhotonNetwork.CloseConnection) when it sees this flag. If nothing happens after clicking this, it almost always means that script isn't running in your game yet — the button itself is working correctly.

Set up your game (one-time)

For kick/ban to actually take effect, and for the server lookup above to show anyone, your game needs:

For kicking: 1) set Photon's UserId to the player's PlayFabId when connecting (PhotonNetwork.AuthValues = new AuthenticationValues(playFabId)), 2) enable Photon's CloseConnection feature (off by default), and 3) attach KickWatcher.cs to a persistent GameObject in your scene.

For the server lookup: attach RoomPresenceReporter.cs to a persistent GameObject too. It reports "I joined/left room X" to PlayFab via the new reportRoomJoin / reportRoomLeave CloudScript handlers, which is what populates the dropdown above. Without it, room lookup will always come back empty.
